# Обложки 🌸
Кидай сюда картинки обложек, например `sad.jpg`.
Потом в `data/novels.json` у нужной новеллы поменяй:
"cover": "assets/covers/sad.jpg"
Если cover = null или файла нет — показывается серая заглушка с буквой.
Обложку можно также поставить с телефона: страница новеллы → красный карандаш → «Картинка с телефона».
